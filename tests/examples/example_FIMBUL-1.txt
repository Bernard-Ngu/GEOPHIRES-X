# Example: FIMBUL 1: Fimbul Feedzone Profile Reservoir Model (Reservoir Model 9) with the coupled inflow-wellbore production wellbore model
#
# example_SHR-6 (the 200 deg.C / 36.7 deg.C/km CATF cell with a pumped production well) with the Gringarten reservoir
# model replaced by Reservoir Model 9, which reads the far-field (feedzone) temperature history of the production well
# from a FeedzoneHistory JSON document written by fimbul-python after a Fimbul.jl (JutulDarcy) reservoir simulation.
# GEOPHIRES never runs Julia: the JSON is the whole hand-off, so this example runs wherever GEOPHIRES runs. The
# profile is checked against the deck (depth, bottom-hole temperature, flow rate per well, fracture height),
# resampled onto the GEOPHIRES time vector and used as the reservoir output temperature; the fracture geometry,
# reservoir volume, hydrostatic pressure and productivity-index drawdown still come from the deck, exactly as for
# the Gringarten model, so the production pump, plant path and economics are unchanged in kind.
#
# The committed profile tests/examples/fimbul_profiles/example_FIMBUL-1.json is a synthetic, Gringarten-shaped
# single-phase liquid history generated from example_SHR-6's reservoir output temperature (see
# tests/geophires_x_tests/test_fimbul_reservoir.py), so this example reproduces example_SHR-6 closely; a profile from
# an actual Fimbul run has the same format. Profiles from Fimbul's pressure-enthalpy water model
# (invariants.fluid_system H2O) are read the same way, with the maximum vapor saturation reported in place of the
# saturation margin.
#
# Requires the superhot-wellbore package:
#   pip install git+https://github.com/softwareengineerprogrammer/superhot-wellbore.git@geophires-client
